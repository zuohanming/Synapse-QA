## 执行器有头浏览器页面元素拾取

- 变更内容：新增采集命令客户端、2 秒轮询器、单采集会话管理器和 Playwright headed picker，仅允许已安装的 Chrome/Edge channel。工具条与高亮使用 Shadow Root，支持 pick/operate、Alt 临时反转、Esc 全局清除、open Shadow DOM、同源 iframe，并明确拒绝跨域 iframe。DOM binding 使用固定字段/属性 allowlist，网页提供的 selector、input value、storage、Cookie、Authorization 与 outerHTML 不进入 Python；Task 5 前后执行独立敏感扫描，定位器匹配数由可信 Playwright frame 复算。局部截图会遮罩 password、tel 和身份标识输入框，使用随机系统临时文件并在上报、停止、过期、401、冲突、失败或应用关闭时清理。
- 影响范围：执行器 FastAPI 生命周期会同时管理普通心跳和唯一采集 poller；`/health` 增加不含 token、receipt 和 URL 的采集状态。GUI 通过 Tk 主线程回调显示“正在采集 · 页面名”，结束后恢复运行状态，采集回调 401 与普通心跳 401 合并为一次登录失效通知。采集 BrowserContext 独立于 `TaskManager`，不占普通任务并发槽位。
