## 执行器有头浏览器页面元素拾取

- 变更内容：新增采集命令客户端、2 秒轮询器、单采集会话管理器和 Playwright headed picker，仅允许已安装的 Chrome/Edge channel。工具条与高亮使用 Shadow Root，支持 pick/operate、Alt 临时反转、Esc 全局清除、open Shadow DOM、同源 iframe，并明确拒绝跨域 iframe。DOM binding 使用固定字段/属性 allowlist，网页提供的 selector、input value、storage、Cookie、Authorization 与 outerHTML 不进入 Python；Task 5 前后执行独立敏感扫描，定位器匹配数由可信 Playwright frame 复算。局部截图会遮罩 password、tel 和身份标识输入框，使用随机系统临时文件并在上报、停止、过期、401、冲突、失败或应用关闭时清理。
- 影响范围：执行器 FastAPI 生命周期会同时管理普通心跳和唯一采集 poller；`/health` 增加不含 token、receipt 和 URL 的采集状态。GUI 通过 Tk 主线程回调显示“正在采集 · 页面名”，结束后恢复运行状态，采集回调 401 与普通心跳 401 合并为一次登录失效通知。采集 BrowserContext 独立于 `TaskManager`，不占普通任务并发槽位。

## 有头采集最终安全收口

- 变更内容：picker 改为 Python 256-bit nonce 与不可从网页全局取得的闭包控制器，校验 page/frame/origin/owner frame 并从元素 handle 复核 DOM；同源 frame 控制器支持全量广播，pick 增加速率、单飞和待上报容量限制。Task 5/6 共用 URL 与敏感数据清洗模块，对 camelCase 敏感键、路径内嵌 token/JWT、常见 secret 和高熵值统一门禁。截图改为 page clip + Playwright mask，不注入 DOM overlay，并补齐 iframe 敏感输入、并发锁、异常清理和文件重试。
- 影响范围：采集 BrowserContext 对每个请求执行 DNS/SSRF 校验，默认拒绝内网、loopback、link-local 和 metadata，仅允许显式 origin/private-host 白名单；平台 HTTP 禁止重定向携带凭据并限制 1 MiB 响应体。后端 start ACK 支持相同 receipt 的安全重试且不轮换 token，候选通过 `clientCaptureId` 和数据库唯一约束实现端到端幂等。401、poller、FastAPI lifespan 和 GUI Tk 主线程队列的关闭顺序统一，`/health` 只保留 active/mode。Windows 临时文件依赖系统临时目录继承的当前用户 ACL，不宣称 POSIX `chmod` 能配置 DACL。
- 验证结果：执行器全量 `131 passed, 2 skipped`，默认跳过的两项本机 headed Edge 测试已分别显式运行并均为 `1 passed`；后端 `go test ./... -count=1` 与 `go vet ./...` 通过。真实 PostgreSQL 覆盖 start ACK/租约状态矩阵、候选重试幂等和历史迁移幂等，全部通过；`python -m compileall -q app gui.py` 与 `git diff --check` 通过。
