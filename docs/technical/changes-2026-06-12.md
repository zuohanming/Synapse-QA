# 2026-06-12 修改记录

## 测试配置

- 项目产品列表操作列新增“模块”入口。
- 新增产品模块配置页，支持当前产品下模块的查询、新增、编辑、删除、分页。
- 新增后端 `product_modules` 表及产品模块 CRUD 接口。
- 新增前端 `configService.productModules` 服务封装。

## 界面自动化

- 页面元素新增/编辑时支持项目产品与模块联动。
- 页面步骤列表筛选支持项目产品、模块、所属页面级联关联。
- 页面步骤新增/编辑弹窗支持项目产品 -> 模块 -> 所属页面三级联动。
- 页面步骤操作列补充“编辑”，保留调试、步骤、更多操作。

## 流程画布

- 页面步骤工作台画布默认空白。
- 左侧组件支持拖入画布生成节点。
- 画布支持 20% 到 300% 缩放，步长 10%。
- 支持鼠标滚轮缩放、按钮缩放、100% 快速复位。
- 缩放时以鼠标位置为锚点。
- 画布节点支持左键拖动。
- 画布空白区域支持按住拖动平移视口。

## 路由与刷新恢复

- 新增前端路由状态持久化工具 `routeState.js`。
- 刷新后恢复当前菜单页面，不再默认跳回首页。
- 支持产品模块配置页、页面元素配置页、页面步骤工作台等内部子页面刷新恢复。
- 对路由状态设置 24 小时有效期，并清理过期数据。
- 无效路由状态会兜底回首页，避免空白页或 404。

## 验证

- 前端执行 `npm run build` 通过。
- 后端执行 `go build ./cmd/api` 通过。
- 浏览器验证了页面步骤联动、页面元素联动、产品模块页面跳转、刷新恢复、画布节点拖动与画布平移等关键场景。
