# 接口管理搜索区与自适应列表设计

## 目标

在桌面浏览器 100% 缩放下优化“接口自动化 / 接口管理”页面：

- 搜索字段保持单行排列，不因当前内容区宽度换行。
- 列表完整适配可用宽度，不出现横向滚动条。
- 全部现有字段和操作保持可见。
- 超长内容使用省略号，并继续通过气泡提示查看全文。
- 不修改筛选、分页、接口请求或其他业务逻辑。

## 搜索区

搜索区使用一行七段式弹性网格：

1. 名称或路径：`1.35fr`，作为主要搜索字段。
2. 项目/产品：`1.25fr`。
3. 模块名称：`1fr`。
4. 方法：`0.72fr`。
5. 接口状态：`0.82fr`。
6. 数据范围：`0.82fr`。
7. 搜索与重置：内容宽度，不参与拉伸。

桌面内容区宽度大于等于 900px 时始终单行。字段最小宽度允许压缩到 92–120px，标签和输入控件保持完整可操作。小于 900px 时沿用移动端纵向布局，避免通过缩小字体或制造页面横向滚动强行保持单行。

## 列表列宽

接口列表宽度固定为容器的 `100%`，使用 `table-layout: fixed`，不设置超过容器的最小总宽度。列宽按信息优先级分配：

| 字段 | 宽度 |
| --- | --- |
| 选择 | 3% |
| ID | 4% |
| 项目/产品 | 12% |
| 模块名称 | 9% |
| 接口名称 | 11% |
| 方法/路径 | 21% |
| 端类型 | 7% |
| 接口状态 | 8% |
| 最近调试 | 8% |
| 最近修改 | 10% |
| 操作 | 7% |

方法标签保持可见，路径占用剩余空间并截断；最近修改允许用户名和时间分两行显示；操作保持单行紧凑排列。文本真实溢出时使用现有可访问气泡提示显示完整内容。

## 实现边界

- 为通用 `DataTable` 增加可选的 `fitContainer` 模式，避免影响其他需要横向滚动的复杂表格。
- 仅接口管理页启用容器适配模式，并为各列声明百分比宽度。
- 搜索区通过接口管理页专属类覆盖，不改变请求头管理等其他复用 `.api-filter-grid` 的页面。
- 保留现有左侧资源树、筛选状态、批量操作、分页和弹窗逻辑。

## 验收标准

- 1440×900、浏览器 100% 缩放：搜索区为一行。
- 接口列表容器的 `scrollWidth` 不大于 `clientWidth`。
- 表格右侧“最近修改”和“操作”无需横向滚动即可看到。
- 字段截断时气泡可通过鼠标悬停和键盘聚焦显示。
- 筛选、重置、分页、调试、编辑和删除行为不变。
- 前端测试与生产构建通过。
