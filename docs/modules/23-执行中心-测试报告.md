# 执行中心 - 测试报告

> 模块定位：汇总执行批次统计、趋势与批次级/任务级报告。

## 1. 模块定位

测试报告模块面向执行结果分析，提供全局统计（通过率、批次与用例规模、趋势）、批次列表与报告详情，并对失败任务提供集中分析区域，支持导出 HTML 报告。

## 2. 功能清单

- ✅ 全局统计：累计通过率（环形核心指标 + 前 7 天环比）、累计执行批次、累计执行用例、失败批次（附执行中数）
- ✅ 近 14 天质量脉冲图（柱高 = 用例量，绿色覆盖 = 通过率）
- ✅ 批次列表：批次 ID、类型、状态、进度、用例数、通过/失败、触发人、开始时间
- ✅ 批次筛选（批次 ID、执行类型、状态）与刷新
- ✅ 报告详情：批次结论、通过率、任务总数/通过/失败、执行耗时、执行信息
- ✅ 任务级明细：展开任务卡查看执行输出与错误信息（默认展开首个失败项）
- ✅ 失败定位：最多 3 条失败任务（用例#/错误/执行器#）
- ✅ 导出 HTML 报告（`synapse-report-{id}.html`，含样式）
- ✅ 无数据时展示零值与空状态

## 3. 操作流程

1. 进入"执行中心 / 测试报告"。
2. 查看顶部全局统计与近 14 天趋势。
3. 在批次列表筛选并定位批次，点击"查看报告"打开报告弹窗。
4. 在报告中查看结论、指标、失败定位与用例执行明细。
5. 点击"导出 HTML"下载报告文件。

## 4. 业务规则

- 通过率 = 累计通过用例数 ÷ 累计用例数；等待/运行/取消/跳过项不计入通过数。
- 统计优先调用统计接口；失败时前端降级为分页拉取全部执行记录自算。
- 报告统计当前覆盖 `execution_runs`，不含接口测试运行批次（边界）。
- 质量结论文案按失败情况生成：存在失败用例 / 全部通过 / 暂无可分析用例。

## 5. 相关接口

- `GET /api/executions`、`GET /api/executions/statistics`、`GET /api/executions/:id`
- 关键数据表：`execution_runs`（summary jsonb：total、passed、failed、skipped、waiting、active）、`execution_tasks`
