# 执行器

> 模块定位：独立于平台的执行代理，接收任务、调度 Runner 执行并回传结果。

## 1. 模块定位

执行器是独立部署的执行代理（Python + FastAPI），负责接收平台下发的任务、通过线程池并发调度各类 Runner 执行，并实时上报心跳、进度与最终结果。支持无界面服务与桌面 GUI 两种运行形态，可打包为 Windows EXE。

## 2. 功能清单

- ✅ 任务提交、任务列表、任务详情、任务取消（HTTP 接口）
- ✅ 任务类型：noop / script / api / api_case / ui（Playwright）/ unit（Pytest）
- ✅ 线程池并发执行（max_workers 可配）
- ✅ 队列上限保护（活动任务达 `max_workers×2` 拒绝入队）
- ✅ 平台注册与周期心跳（默认 10 秒）
- ✅ 依赖自检上报（pytest、playwright、browser）
- ✅ 完成/失败/取消后回调平台
- ✅ API 调试实时事件回调（request/response/extractor/assertion 序列）
- ✅ 桌面 GUI：Token 登录、启动/停止服务、健康检查、运行日志终端、环境面板
- ✅ 打包为 Windows EXE（PyInstaller，无控制台窗口）
- 🚧 取消运行中任务：仅 api/api_case 响应取消；ui/script/unit 底层进程继续执行完
- 🚧 回调无鉴权、无重试（单次尝试，失败记日志）
- ⬜ 无沙箱（script/pytest/pythonCode 以执行器进程权限运行）；SSRF 防护允许私有网段

## 3. 操作流程

1. 在平台"测试配置 / 执行器配置"生成并复制共享 Token。
2. 启动执行器：`python main.py`（无界面）或 `python gui.py`（桌面，输入 Token 连接）。
3. 执行器启动后向平台注册并持续心跳，平台可调度任务。
4. 平台下发任务 → 执行器登记 → 线程池异步执行 → 回传进度与结果。

## 4. 业务规则

- 注册/心跳使用 `X-Executor-Token` 请求头；鉴权失败（401）停止心跳并回到登录态。
- 任务状态流转：queued → running → success | failed | canceled。
- 回调以平台任务 ID 为一次性凭据，不使用用户 Bearer Token。
- UI 任务基于 Playwright，支持有头/无头与画布流程图（检测循环）。
- API 任务：HTTP 请求 + gzip/deflate 解压 + 提取器（jsonpath 子集/regex/header/status）+ 断言（11 种操作符）+ SSRF 防护 + 20MiB 大小限制 + 300 秒超时。
- API Case：串行多步执行，变量上下文跨步骤传递，支持阶段与失败策略。
- SQL 节点只读事务、连接与语句超时 10 秒；Python 节点以子进程隔离执行、10 秒超时。
- 当前任务存内存，重启即丢失；UI 截图落本地 artifacts 目录，不主动上传平台。

## 5. 相关接口

- 执行器侧：`GET /health`、`POST /tasks`、`GET /tasks`、`GET /tasks/{id}`、`POST /tasks/{id}/cancel`
- 平台侧：`POST /api/executors/register`、`POST /api/executors/heartbeat`、`POST /api/executions/tasks/:taskId/callback`、`POST /api/api-automation/debug/:taskId/callback`、`POST /api/api-automation/debug/:taskId/events/callback`、`POST /api/api-automation/test-runs/tasks/:taskId/callback`
- 关键配置（环境变量）：`EXECUTOR_ID`、`EXECUTOR_NAME`、`EXECUTOR_ENDPOINT`、`EXECUTOR_SHARED_TOKEN`、`PLATFORM_BASE_URL`、`EXECUTOR_MAX_WORKERS`、`EXECUTOR_HEARTBEAT_INTERVAL_SECONDS`、`EXECUTOR_ARTIFACTS_DIR`
