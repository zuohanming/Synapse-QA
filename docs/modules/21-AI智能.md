# AI 智能

> 模块定位：接入大模型能力，提供模型配置、偏好设置与对话式助手（Copilot）。

## 1. 模块定位

AI 智能模块打通大模型接入链路：用户自行配置模型（服务商、模型名、API Key、Base URL），设置各场景偏好，并通过流式对话界面与 AI 助手交互。AI 助手支持 Tool Calling，可通过自然语言操作系统功能。

## 2. 功能清单

- ✅ 模型管理：新建、编辑、删除、启停（按用户隔离）
- ✅ 服务商：OpenAI / DeepSeek / Anthropic / Google Gemini / OpenRouter（切换自动填充默认 Base URL）
- ✅ 连接测试（展示延迟）与"测试并保存"
- ✅ 场景偏好：AI 助手、智能断言、用例生成、失败分析分别绑定默认模型
- ✅ 安全策略展示（只读）：数据脱敏、单次最大 Token、速率限制
- ✅ AI 助手聊天：SSE 流式对话、打字动画、历史记录（本地存储 50 条）、清空对话
- ✅ Tool Calling：工具调用过程展示（执行中/成功/失败），可自然语言操作系统功能
- ✅ 工具集 28 个：接口（search/create/get/delete/update）、产品模块（list/create/update/delete）、项目、测试用例、执行记录、测试环境
- ✅ 工具自动发现：未传项目/产品时自动取系统第一个
- ⬜ 智能断言建议、用例生成、失败分析：均为"规划中"占位卡片，无实际功能
- ⬜ 安全策略中的 dataMasking、rateLimitPerMinute 仅存储未生效；实际仅应用单次最大 Token

## 3. 操作流程

1. 进入"AI 智能 / AI 设置"，新建并启用至少一个模型（可"测试并保存"）。
2. 在"场景偏好"为各场景绑定默认模型。
3. 进入"AI 助手"，输入自然语言提问；系统流式返回并展示工具调用过程。
4. 通过自然语言发起系统操作（如"创建接口""查询执行记录"），AI 自动识别意图并调用对应工具。

## 4. 业务规则

- 模型配置按用户隔离存储（`platform_settings` 的 `ai.config.<userId>`）。
- 各服务商接入差异：Anthropic 使用 `x-api-key` + `anthropic-version` 头；Gemini 使用 query key。
- 对话流程：非流式请求探测 tool_calls → 执行工具 → 追加消息，最多 5 轮；最终回答走流式 SSE。
- SSE 事件类型：model / tool_call / tool_result / content / done / error。
- 系统提示词固定为"你是 Synapse QA 测试平台的 AI 助手…"；temperature=0.7；`max_tokens` 取安全策略（默认 4096）。
- AI 发起的操作以"AI助手"名义写入操作日志。
- 未配置默认模型/未启用/无 API Key 时调用报错。

## 5. 相关接口

- `GET /api/ai/config`、`POST /api/ai/models`、`DELETE /api/ai/models/:id`、`POST /api/ai/test-connection`、`POST /api/ai/preferences`、`POST /api/ai/chat`
- 关键数据表：`platform_settings`（key = ai.config.<userId>，结构 AIConfig{models, preferences, security}）
