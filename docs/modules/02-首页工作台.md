# 首页工作台

> 模块定位：登录后的默认落地页，集中展示平台核心资产数量概览。

## 1. 模块定位

首页工作台是平台主入口，以卡片形式概览测试资产、平台用户与权限角色的总体规模，帮助使用者快速掌握平台资产状况。当前为只读概览页，不承载具体业务操作入口。

## 2. 功能清单

- ✅ 顶部横幅与资产总量汇总（7 张卡片数值之和）
- ✅ 七张指标卡：测试项目、产品模块、测试对象、页面元素、UI 资产、平台用户、权限角色
- ✅ 无数据时展示明确的零值与空状态
- ⬜ 卡片跳转：当前卡片不是可点击入口，不承载跳转能力

## 3. 操作流程

1. 登录成功后默认进入"首页 / 项目概览"。
2. 浏览七张指标卡获取各资产维度数量。
3. 通过左侧菜单或顶栏面包屑进入其他模块。

## 4. 业务规则

- 数据来源于系统概览接口，统计口径与"系统管理 / 系统概览"一致。
- 页面为只读展示，不提供刷新或筛选交互。

## 5. 相关接口

- `GET /api/system/overview`（返回 projects / products / testObjects / pageElements / uiAssets / users / roles）
- 关键数据表：`projects`、`products`、`test_objects`、`page_elements`、`ui_assets`、`users`、`roles`
