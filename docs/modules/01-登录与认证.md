# 登录与认证

> 模块定位：平台统一入口，负责账号登录、会话签发、首次登录改密与登录态失效处理。

## 1. 模块定位

登录与认证是 Synapse QA 平台的访问入口。用户通过账号密码登录后获得平台访问令牌，平台 API 除健康检查、登录、注册和执行器回调外，默认要求携带有效令牌。系统内置安全策略对登录失败进行锁定，并在密码变更、权限变化后自动使旧会话失效。

## 2. 功能清单

- ✅ 用户名、密码登录
- ✅ 登录态恢复：刷新页面后自动恢复会话（`/auth/me`）
- ✅ 令牌失效/过期自动清理并返回登录页
- ✅ 首次登录强制修改临时密码
- ✅ 修改登录密码（改后重新签发令牌）
- ✅ 连续登录失败锁定账号，到期自动解锁或由管理员解锁
- ✅ 登录页展示演示账号提示，并默认预填 `admin / admin123`
- ⬜ 公开注册入口（`/auth/register`）：已实现接口，注册用户无角色分配，仅作公开入口存在

## 3. 操作流程

1. 打开平台地址，进入登录页。
2. 输入用户名、密码，点击登录。
   - 默认演示账号：`admin / admin123`。
3. 登录成功进入工作台；若账号标记为"首次登录需改密"，则强制进入改密页。
4. 改密页输入当前临时密码、新密码与确认密码（新密码至少 8 位且同时包含字母和数字），保存后重新签发令牌进入平台。
5. 令牌无效或过期时，平台自动清理本地登录状态并回到登录页。

## 4. 业务规则

- 令牌为平台自实现签名令牌（`base64url(payload) + HMAC-SHA256`），携带用户 ID、用户名、角色、权限、`authVersion` 与过期时间。
- 会话时长取安全策略 `sessionHours`（默认 24 小时，范围 1–720）。
- 每次请求都会重新校验用户状态与 `authVersion`；修改密码、重置密码或角色权限变更会使 `authVersion` 自增，旧令牌立即失效。
- 密码规则：长度 ≥ `passwordMinLength`（默认 8，范围 8–32），必须同时包含字母和数字；新密码不得与当前密码相同。
- 登录失败锁定：密码错误达到 `loginFailureLimit`（默认 5，范围 3–20）次后锁定 `lockMinutes`（默认 15 分钟，范围 1–1440）；锁定期间登录提示"账号已锁定"；登录成功后清零计数。
- 停用账号登录统一返回"用户名或密码错误"，不泄露账号状态。

## 5. 相关接口

- 公开：`POST /api/auth/login`、`POST /api/auth/register`
- 登录后：`GET /api/auth/me`、`POST /api/auth/change-password`
- 关键数据表：`users`（账号与密码摘要、锁定计数、`authVersion`、`must_change_password`）、`operation_logs`（登录动作留痕）、`platform_settings`（安全策略参数）
