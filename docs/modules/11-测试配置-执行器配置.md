# 测试配置 - 执行器配置

> 模块定位：管理平台级执行器接入凭据，配置执行器专属 Token 与共享 Token。

## 1. 模块定位

执行器配置面向平台侧的接入管理，包括执行器共享 Token 的查看与再生成，并展示执行器专属 Token 的配置方式。执行器的状态与负载信息在"系统概览"或调度时体现。

## 2. 功能清单

- ✅ 执行器共享 Token 当前值展示（脱敏：前 10 位 + ... + 后 6 位）与更新时间
- ✅ 重新生成共享 Token（生成后原 Token 失效）
- ✅ 一键复制执行器配置（`EXECUTOR_SHARED_TOKEN=...` 环境变量命令）
- ✅ 环境变量配置命令预览（`token-output`）

## 3. 操作流程

1. 进入"测试配置 / 执行器配置"。
2. 查看当前共享 Token 脱敏值；如需更换，点击"生成 Token"并确认。
3. 点击"复制配置"复制环境变量命令，在启动执行器的机器上配置 `EXECUTOR_SHARED_TOKEN`。
4. 执行器启动后向平台注册并通过心跳维持在线状态。

## 4. 业务规则

- 共享 Token 存储于 `platform_settings.executor_shared_token`，生成格式为 `syn_exec_` + 48 位 hex。
- 执行器鉴权优先使用其专属 Token，无专属 Token 时回落共享 Token。
- 专属 Token 失配会广播"执行器 Token 已失效"通知。
- 执行器在线判定：注册后按心跳刷新；最近心跳超过 30 秒标记"可疑"，超过 60 秒标记"离线"（列表展示口径）。

## 5. 相关接口

- `GET /api/config/executor-token`、`POST /api/config/executor-token/generate`
- 关联：`POST /api/executors/register`、`POST /api/executors/heartbeat`（公开，执行器侧调用）
- 关键数据表：`platform_settings`（executor_shared_token）、`executors`（executor_id、executor_token、last_heartbeat_at、running_tasks、queued_tasks、supported_types、checks）
