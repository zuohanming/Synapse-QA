# 测试配置 - 测试对象

> 模块定位：定义产品在某环境中的可访问目标，为执行与变量解析提供环境来源。

## 1. 模块定位

测试对象描述"产品 × 环境 → 被测地址"的关系，承载部署环境、自动化类型、负责人与读写开关等属性。环境级全局变量及执行上下文依赖测试对象确定目标地址。

## 2. 功能清单

- ✅ 测试对象列表查询（只读展示：项目·产品 / 环境 / 测试对象 / 负责人）
- ✅ 后端支持完整 CRUD（新增、编辑、删除）
- ⬜ 前端测试对象子页当前仅只读表格，无新增/编辑/删除/分页操作入口

## 3. 操作流程

1. 进入"测试配置 / 测试对象"。
2. 当前前端仅可浏览列表数据。
3. 后端接口可用于其他端或后续迭代维护测试对象。

## 4. 业务规则

- 测试对象必填：产品、环境名、目标地址、负责人。
- `deploy_env` 默认"生产环境"；`auto_type` 默认"界面自动化"。
- 同一产品下环境名称唯一。
- `query_enabled` 默认开启；`write_enabled` 默认关闭。
- 环境级全局变量解析时按产品 + 环境名匹配测试对象。

## 5. 相关接口

- `GET /api/config/test-objects`、`POST /api/config/test-objects`、`PATCH /api/config/test-objects/:id`、`DELETE /api/config/test-objects/:id`
- 关键数据表：`test_objects`（product_id、env_name、target、deploy_env、auto_type、owner、query_enabled、write_enabled，unique(product_id,env_name)）
