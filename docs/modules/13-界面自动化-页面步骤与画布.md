# 界面自动化 - 页面步骤与画布

> 模块定位：以可视化画布编排可复用的 UI 操作流程（页面步骤）。

## 1. 模块定位

页面步骤是可复用的 UI 操作序列或画布流程。平台提供可视化画布，支持从左侧操作面板拖入节点、节点拖动、画布平移与缩放，并通过节点类型（元素操作、断言、SQL、变量、条件、Python 代码）编排执行逻辑。步骤可作为测试用例的关联步骤被引用执行。

## 2. 功能清单

- ✅ 步骤列表、筛选（ID、步骤名称、项目/产品、模块、所属页面、状态）
- ✅ 步骤新增、编辑、删除、复制、批量删除
- ✅ 步骤表单：项目/产品、模块、所属页面、步骤名称、状态、预估步骤顺序
- ✅ 画布工作台：左侧 6 类节点面板（元素操作/断言操作/SQL操作/自定义变量/条件判断/Python代码）
- ✅ 画布能力：拖入创建节点、节点自由拖动、画布平移、滚轮/±/100% 缩放（0.2–3 倍）、小地图、画布统计
- ✅ 节点详情：元素操作下拉（WEB/安卓约 200 项操作）+ 备注；"调试结果"tab 骨架
- 🚧 画布连线、保存画布、调试、美化画布按钮为占位（无处理逻辑）；节点配置仅"元素操作+备注"可用
- 🚧 后端已具备画布 JSON 校验与转 Playwright 执行能力，但前端画布尚未完整接通保存与调试链路

## 3. 操作流程

1. 进入"界面自动化 / 页面步骤"。
2. 新增步骤：填写项目/产品、模块、所属页面与步骤名称。
3. 点击步骤行的"步骤"或"调试"进入画布工作台。
4. 从左侧面板拖入节点，摆放节点（当前未实现连线与保存）。
5. 在右侧配置"元素操作"类型并填写备注。

## 4. 业务规则

- 画布 JSON 结构：`{"schema":"synapse-flow-v1","nodes":[...],"connections":[...]}`，节点含 `tag`、`operationName`、`values`。
- 节点 tag 映射动作：打开页面、等待、点击、双击、输入、清空、悬停、截图；文本/标题/URL/元素存在性/可见性/启停/勾选/值/属性/数量/变量/正则断言；SQL 查询；设置变量；条件判断；Python 代码。
- 校验规则：schema 必须为 `synapse-flow-v1`；必须只有一个起始节点（无入边）；条件节点必须同时连接 true/false 分支；未知 tag 报"不支持的节点操作"。
- 变量引用统一使用 `${变量名}` 语法。
- Python 代码节点在执行器进程内运行，当前未提供沙箱隔离，不应执行不可信代码。
- SQL 节点执行只读事务，连接与语句超时 10 秒。

## 5. 相关接口

- `GET/POST /api/ui/steps`、`PATCH/DELETE /api/ui/steps/:id`（通用资源，asset_type=page_step）
- 执行：`POST /api/executions/debug`、`GET /api/executions/debug/:taskId`、`GET /api/executions/tasks/:taskId/logs`
- 关键数据表：`ui_assets`（asset_type=page_step，description 存画布 JSON）
