# 系统管理 - 外观设置

> 模块定位：定制平台界面主题、字体、字号与显示密度，修改即时生效。

## 1. 模块定位

外观设置允许用户按个人偏好定制界面呈现，包括主题、界面字体、代码字体、字号与显示密度。设置保存在浏览器本地并即时生效，无需后端参与。

## 2. 功能清单

- ✅ 界面主题 5 选 1：蓝图网格、午夜作战、精密实验室、管理驾驶舱、工业信号（带预览色块）
- ✅ 界面字体：系统默认 / 微软雅黑 / 思源黑体
- ✅ 代码字体：Consolas / Cascadia Code / JetBrains Mono
- ✅ 字体大小三组（界面文字 / 表格文字 / 代码与日志）× 三档（小 / 标准 / 大）
- ✅ 显示密度：紧凑 / 标准 / 宽松
- ✅ 修改即时生效并持久化到浏览器本地
- ⬜ 旧版主题（codex/wechat/kimi）样式仍存在于样式文件中，但当前界面无入口选择

## 3. 操作流程

1. 进入"系统管理 / 外观设置"。
2. 选择主题、字体、字号与密度，页面即时预览效果。
3. 设置自动保存至浏览器本地，下次访问自动恢复。

## 4. 业务规则

- 外观设置仅保存在浏览器本地（`localStorage`），不随账号同步，不同浏览器/设备需分别设置。
- 登录页与平台主界面共用主题变量，保证视觉一致。

## 5. 相关接口

- 无后端接口（纯前端本地存储）
- 关联文件：`frontend/src/utils/appearance.js`、`frontend/src/styles/appearance.css`
