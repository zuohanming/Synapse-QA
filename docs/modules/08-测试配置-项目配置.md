# 测试配置 - 项目配置

> 模块定位：维护平台顶层业务组织单元——项目。

## 1. 模块定位

项目是平台资产组织的顶层单元，产品、模块、测试对象、页面、步骤、用例与接口均归属于项目。项目配置提供项目的分页查询、新增、编辑、启停用与删除能力。

## 2. 功能清单

- ✅ 项目分页查询与按 ID、项目名称筛选
- ✅ 新增、编辑项目（名称、状态）
- ✅ 启用 / 停用项目
- ✅ 单个删除与批量删除（软删除，删除前确认）

## 3. 操作流程

1. 进入"测试配置 / 项目配置"。
2. 新增：点击"新增"，填写项目名称并选择状态（启用/停用），提交后提示"项目已创建"。
3. 编辑：点击"编辑"，修改后保存。
4. 删除：勾选一个或多个项目，点击"删除/批量删除"并确认。

## 4. 业务规则

- 项目名称唯一。
- 项目状态枚举：`active` / `disabled`。
- 删除采用软删除，删除后不再出现在正常列表，历史关联记录保留。

## 5. 相关接口

- `GET /api/config/projects`、`POST /api/config/projects`、`PATCH /api/config/projects/:id`、`DELETE /api/config/projects/:id`
- 关键数据表：`projects`（name unique、status、updated_at、deleted_at）
