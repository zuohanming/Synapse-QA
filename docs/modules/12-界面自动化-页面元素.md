# 界面自动化 - 页面元素

> 模块定位：以"页面对象 → 元素定位"两级结构维护界面自动化定位资产。

## 1. 模块定位

页面元素模块在项目、产品、模块与页面维度下维护页面对象，并在页面下配置多级元素定位策略（类型、定位值、索引），支持 AI 定位提示与等待时间辅助配置，为页面步骤与用例提供元素基础。

## 2. 功能清单

- ✅ 页面对象列表、筛选（ID、页面名称、页面地址、项目/产品、模块名称）
- ✅ 页面对象新增、编辑、删除、复制、批量删除
- ✅ 页面对象表单：项目/产品、模块、页面名称、页面地址、端类型、状态、说明
- ✅ 页面元素配置面板：单个新增、批量删除
- ✅ 多级定位策略：类型/定位/索引 各 3 组（xpath/css/id/name/text）
- ✅ 元素字段：元素名称、等待时间（秒）、AI 提示词
- ✅ 已选页面的页面级状态记忆（刷新后保持所在页面）
- ⬜ 元素面板"下载模板、点击上传"按钮无处理逻辑（占位）
- ⬜ 元素行内"调试"按钮无处理逻辑（占位）
- ⬜ 页面对象复制支持有限：仅"更多 → 复制"入口，部分交互待完善

## 3. 操作流程

1. 进入"界面自动化 / 页面元素"。
2. 新增页面对象：填写项目/产品（联动模块）、页面名称、页面地址等。
3. 点击页面行的"添加元素"进入该页面元素配置面板。
4. 点击"单个新增"添加元素，填写元素名称、等待时间与 1–3 组定位策略。
5. 保存后元素即供页面步骤画布引用。

## 4. 业务规则

- 页面对象与元素采用软删除。
- 页面元素必填：页面、元素名称、type1、locator1。
- 端类型展示为 WEB / APP 徽标。
- 存在两套并存机制：通用 `ui_assets`（asset_type=page_element）与独立 `page_elements` 表，当前前端主要使用后者。

## 5. 相关接口

- `GET/POST /api/ui/elements`、`PATCH/DELETE /api/ui/elements/:id`（通用资源，asset_type=page_element）
- `GET/POST /api/ui/page-elements`、`PATCH/DELETE /api/ui/page-elements/:id`（独立表）
- 关键数据表：`ui_assets`（asset_type、name、category、locator、action、value、status、deleted_at）、`page_elements`（page_id、name、type1/2/3、locator1/2/3、index1/2/3、ai_prompt、wait_time）
