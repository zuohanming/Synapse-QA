# 接口自动化 - 接口全局变量

> 模块定位：维护接口自动化执行链路共享变量，支持多级作用域与类型。

## 1. 模块定位

接口全局变量为接口测试提供运行期可引用的数据，支持系统、项目、产品三级作用域与字符串/数字/布尔/JSON/密钥类型，执行时按变量优先级解析 `${变量名}`。

## 2. 功能清单

- ✅ 变量 CRUD（新增、编辑、删除）
- ✅ 作用域：系统 / 项目 / 产品
- ✅ 类型：string / number / boolean / json / secret
- ✅ 环境名称（留空 = 全部环境）
- ✅ 敏感变量标记（secret 类型自动强制敏感）
- ✅ 变量值与密钥输入/脱敏展示
- ✅ 筛选：搜索变量名或说明、作用域、项目、产品
- ✅ 覆盖顺序提示条（步骤临时变量 → 提取变量 → 数据集 → 用例变量 → 接口变量 → 产品变量 → 项目变量 → 系统变量）

## 3. 操作流程

1. 进入"接口自动化 / 全局变量"。
2. 新增变量：选择作用域（系统/项目/产品），按需选择项目、产品与环境名称，填写变量名、类型、值与说明。
3. 启用/禁用变量；secret 类型以密码框输入并以脱敏形式展示。
4. 在接口测试用例的步骤条件或配置覆盖中使用 `${变量名}` 引用。

## 4. 业务规则

- 变量名规则：`^[A-Za-z_][A-Za-z0-9_]*$`。
- 按作用域 + 环境名解析变量；sensitive 或 secret 类型读写脱敏/加密。
- 引用语法 `${var}`，替换最多 10 层，未定义变量报错。
- 变量覆盖顺序（高 → 低）：步骤临时变量、提取变量、数据集、用例变量、接口变量、产品变量、项目变量、系统变量。

## 5. 相关接口

- `GET/POST /api/api-automation/global-variables`、`PATCH/DELETE /api/api-automation/global-variables/:id`
- 关键数据表：`api_global_variables`（scope_type、project_id、product_id、env_name、name、value_type、value、sensitive、enabled）
