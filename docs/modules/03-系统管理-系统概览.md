# 系统管理 - 系统概览

> 模块定位：面向系统管理员的运行态势工作台，展示平台规模、当日执行与近期管理动作。

## 1. 模块定位

系统概览是系统管理下的第一个子页，汇总账号与角色容量、执行器在线率、今日执行量、失败量、近 7 日执行趋势与最近管理动作，便于管理员快速发现平台运行变化。

## 2. 功能清单

- ✅ 运行态势指标：在线执行器占比、今日执行、今日失败、活跃账号、权限角色
- ✅ 近 7 日执行脉冲：按日展示执行总量与失败量的柱状图
- ✅ 最近管理动作：最近 6 条操作审计记录
- ✅ 权限控制：需 `system.overview.read` 权限，admin 角色默认放行

## 3. 操作流程

1. 进入"系统管理 / 系统概览"。
2. 查看顶部运行指标卡。
3. 查看近 7 日执行趋势柱状图。
4. 查看底部最近管理动作列表（点击可进入操作日志模块）。

## 4. 业务规则

- 在线执行器口径：`last_heartbeat_at` 距今未超过执行策略 `executorOfflineSeconds`（默认 45 秒）视为在线。
- 今日执行量 = 当日 `execution_runs` 与 `api_test_run_batches` 数量之和；失败量 = 当日状态为 failed 的两类批次之和。
- 趋势维度仅统计"总量 / 失败量"，不含通过数维度。

## 5. 相关接口

- `GET /api/system/overview`（权限：`system.overview.read`）
- 关键数据表：`users`、`roles`、`executors`、`execution_runs`、`api_test_run_batches`、`operation_logs`、`system_setting_groups`
