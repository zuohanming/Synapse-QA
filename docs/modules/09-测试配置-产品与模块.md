# 测试配置 - 产品与模块

> 模块定位：在项目下维护被测系统（产品）及其功能模块，作为各自动化资产的联动维度。

## 1. 模块定位

产品归属于项目，模块归属于产品。页面、步骤、用例、接口等资产在选择时通过"项目 → 产品 → 模块"联动加载。本模块提供产品与模块的两级维护入口。

## 2. 功能清单

- ✅ 产品分页查询与按 ID、产品名称筛选
- ✅ 产品新增、编辑、删除（必填：所属项目、产品名称；可选：UI 端、API 端）
- ✅ 产品模块新增、编辑、删除（一级模块、二级模块、模块名称）
- ✅ 模块导航：左侧按一级/二级组织，支持搜索与计数
- ✅ 已选产品的页面级状态记忆（刷新后保持所在产品模块页）

## 3. 操作流程

1. 进入"测试配置 / 项目产品"，查看产品列表。
2. 新增/编辑产品：填写所属项目、产品名称并选择 UI 端（WEB/APP/H5）、API 端。
3. 点击产品行的"模块"进入该产品的模块管理页。
4. 在模块页左侧浏览模块树，右侧筛选与维护模块；点击"增加"新增模块，填写一级模块、二级模块与模块名称。
5. 点击"返回"回到产品列表。

## 4. 业务规则

- 产品必填"项目 + 名称"；`ui_type` / `api_type` 仅允许 WEB / APP / 安卓 / IOS / NONE（默认 WEB）；同一项目下产品名称唯一。
- 产品模块必填"产品 + 名称"；level1/level2 为可选层级；同一产品下 `(level1, level2, name)` 唯一。
- 产品模块通过复合外键与接口、接口用例关联。
- 删除为软删除，历史关联保留。

## 5. 相关接口

- `GET /api/config/products`、`POST /api/config/products`、`PATCH /api/config/products/:id`、`DELETE /api/config/products/:id`
- `GET /api/config/product-modules`、`POST /api/config/product-modules`、`PATCH /api/config/product-modules/:id`、`DELETE /api/config/product-modules/:id`
- 关键数据表：`products`（project_id、name、ui_type、api_type，unique(project_id,name)）、`product_modules`（product_id、name、level1、level2，unique(product_id,level1,level2,name)）
