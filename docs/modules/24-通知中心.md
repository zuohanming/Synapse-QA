# 通知中心

> 模块定位：集中展示执行、执行器与系统通知，支持实时推送与偏好设置。

## 1. 模块定位

通知中心收集执行结果、执行器状态变化、系统公告等事件，通过顶栏铃铛入口与未读角标触达用户，支持实时 SSE 推送、单条/全部已读、删除与个人偏好设置。

## 2. 功能清单

- ✅ 顶栏铃铛入口与未读数角标（>99 显示 99+）
- ✅ 通知列表（分类 tab：全部/未读/执行任务/执行器/系统）
- ✅ 单条已读、全部已读、删除
- ✅ 实时推送（SSE 流，断开自动重连）
- ✅ 带跳转地址的通知点击后跳转对应页面
- ✅ 偏好设置：执行成功/执行失败/执行器告警/系统通知 四个开关，或使用系统默认
- ✅ 空态提示

## 3. 操作流程

1. 点击顶栏铃铛打开通知面板，查看未读与分类通知。
2. 点击通知条目：未读先标已读，若有跳转地址则进入对应页面。
3. 点击"全部已读"清空未读标记；点击"删除"移除单条。
4. 点击设置按钮进入偏好设置，调整四个开关或改回系统默认。

## 4. 业务规则

- 通知类型：execution.success / execution.failure / executor.connected / executor.recovered / executor.started / executor.stopped / executor.offline / executor.token / system / queue.congested。
- 偏好过滤在写库时生效：个人偏好（未使用系统默认时）> 系统参数通知组 > 默认 true；system 类型始终投递。
- 定向通知按用户名定位用户；广播通知发给所有 active 用户。
- SSE 心跳 20 秒；广播时向订阅者推送空对象触发前端重新拉取。
- 通知可携带目标类型、目标 ID 与跳转地址。

## 5. 相关接口

- `GET /api/notifications`、`GET /api/notifications/unread-count`、`GET /api/notifications/stream`、`PATCH /api/notifications/:id/read`、`POST /api/notifications/read-all`、`DELETE /api/notifications/:id`
- `GET/PATCH /api/notifications/preferences`、`POST /api/notifications/system`
- 关键数据表：`notifications`（user_id、type、level、title、content、target_type、target_id、target_url、is_read、read_at）、`notification_preferences`（use_system_defaults、execution_success、execution_failure、executor_alert、system_notice）
