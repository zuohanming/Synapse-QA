# 系统管理 - 系统参数与操作日志

> 模块定位：维护平台运行策略参数（执行、安全、通知），并审计关键业务操作。

## 1. 模块定位

系统参数提供执行策略、安全策略、通知默认策略的配置与版本化管理，支持历史查看与回滚；操作日志记录平台关键操作并提供组合筛选与 CSV 导出，为审计与问题追踪提供依据。

## 2. 功能清单

- ✅ 参数组列表与字段编辑（乐观锁版本控制）
- ✅ 版本历史查看与回滚
- ✅ 操作日志多条件筛选与分页
- ✅ 操作日志 CSV 导出
- ✅ 执行策略：默认并发数、最大并发数、批次用例数、执行器离线判定秒数
- ✅ 安全策略：会话有效期、密码最短长度、失败锁定阈值、锁定时长
- ✅ 通知默认策略：执行成功/失败/执行器离线开关；系统告警、安全告警固定开启

## 3. 操作流程

1. 进入"系统管理 / 系统参数"，左侧选择执行策略或安全策略分组。
2. 修改字段后点击"保存"（携带当前版本号，保存成功提示"已对后续业务操作生效"）。
3. 查看版本记录：点击版本列表查看历史快照；点击"回滚"并确认，将目标版本写回为最新配置。
4. 进入"操作日志"子页，按操作人、动作、目标、日期范围筛选；点击"导出 CSV"下载审计数据。

## 4. 业务规则

- 参数组仅三组：`execution`、`security`、`notification`。
- `execution`：defaultConcurrency(1–max)、maxConcurrency(≤500)、batchSize(1–5000)、executorOfflineSeconds(15–600)。
- `security`：sessionHours(1–720)、passwordMinLength(8–32)、loginFailureLimit(3–20)、lockMinutes(1–1440)。
- `notification`：executionSuccess / executionFailure / executorOffline 布尔；systemAlert、securityAlert 强制为 true 不可修改。
- 更新必须携带当前 `revision`，不匹配则拒绝并提示"配置可能已被其他管理员修改"。
- 每次更新写入两条历史记录（变更前快照 + 变更后记录），revision 自增；历史列表最多 50 条。
- 操作日志默认每页 20 条、上限 100；CSV 导出固定取前 5000 条，UTF-8 BOM 编码。
- 记录范围：登录、用户/角色/参数、项目/产品/模块/测试对象、界面/接口自动化资产、测试用例、执行批次、调试等关键动作。

## 5. 相关接口

- 权限组：`system.settings.read`、`system.settings.manage`、`system.audit.read`、`system.audit.export`
- `GET /api/system/settings`、`PATCH /api/system/settings/:groupKey`、`GET /api/system/settings/:groupKey/history`、`POST /api/system/settings/:groupKey/rollback`
- `GET /api/system/logs`、`GET /api/system/logs/export`
- 关键数据表：`system_setting_groups`（group_key、value jsonb、revision）、`system_setting_history`、`operation_logs`（actor、action、target、ip、created_at）
