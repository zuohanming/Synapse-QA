# 系统管理 - 用户管理

> 模块定位：维护平台账号生命周期，包括新增、编辑、启停用、解锁、重置密码与删除。

## 1. 模块定位

用户管理负责平台账号的维护。管理员可创建用户并分配角色，系统自动生成一次性临时密码并要求首次登录修改；支持账号锁定解锁、密码重置、启停用与删除，权限或状态变化后旧登录会话自动失效。

## 2. 功能清单

- ✅ 用户列表与分页（每页 20 条）
- ✅ 按 ID、昵称、账号模糊筛选
- ✅ 新增用户（生成 8 位一次性临时密码，关闭后不可再查看）
- ✅ 编辑用户（账号、昵称、邮箱、角色、状态）
- ✅ 启停用用户
- ✅ 解锁被锁定账号
- ✅ 重置密码（生成新临时密码，并立即使旧会话失效）
- ✅ 删除用户（软删除）

## 3. 操作流程

1. 进入"系统管理 / 用户管理"。
2. 新增：点击"新增用户"，填写登录账号、用户昵称、邮箱与系统角色，提交后弹出一次性临时密码。
3. 编辑：点击"编辑"，修改信息后保存；角色或状态变化时提示"会使旧登录立即失效"。
4. 重置密码：点击"重置密码"，确认后弹出新临时密码。
5. 解锁：对处于锁定状态（`lockedUntil` 未到）的账号点击"解锁"。
6. 停用/启用：点击"停用/启用"并确认；最后一个启用状态的 admin 用户及当前登录用户不可停用。
7. 删除：点击"删除"并确认。

## 4. 业务规则

- 新增用户：系统生成 8 位临时密码（字符集去除易混淆字符），`must_change_password=true`；账号写入 `mcp_api_key`（`mango_` 前缀）。
- 重置密码：生成新临时密码并 `auth_version+1`，立即踢出旧会话。
- 编辑用户：不能停用系统中最后一个启用状态的 admin 角色用户；不能停用当前登录用户本人；状态或角色变化时 `auth_version+1`。
- 解锁：清空失败计数与锁定截止时间。
- 用户状态枚举：`active` / `disabled`（默认 active）；锁定状态由登录失败策略触发。

## 5. 相关接口

- 权限组：`system.user.read`、`system.user.manage`
- `GET /api/system/users`、`POST /api/system/users`、`PATCH /api/system/users/:id`、`POST /api/system/users/:id/unlock`、`POST /api/system/users/:id/reset-password`、`DELETE /api/system/users/:id`
- 关键数据表：`users`（username、password_hash、display_name、email、status、mcp_api_key、role_id、auth_version、must_change_password、failed_login_count、locked_until、last_login_ip、last_login_at、deleted_at）
